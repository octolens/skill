# Octolens Skill

Query and analyze brand mentions from the Octolens API. Track keywords, filter by source platforms (Twitter, Reddit, GitHub, LinkedIn, etc.), perform sentiment analysis, and analyze social media engagement.

## Installation

Install this skill using:

```bash
npx add-skill octolens/skill
```

## Features

- Fetch brand mentions from multiple platforms
- Filter by source, sentiment, date range, and more
- Complex filtering with AND/OR logic
- Sentiment analysis (positive, neutral, negative)
- Filter by follower count and engagement metrics
- Query mentions by keywords and tags

## Requirements

- `curl` for API requests
- `jq` for JSON parsing
- Octolens API key
